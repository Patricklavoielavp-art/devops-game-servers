# FS25 Dedicated Server (Docker)

Ce dossier contient la configuration Docker pour héberger un server Farming Simulator 25 compatible PC, PS5 et Xbox

## Lancer le serveur

docker compose up -d

## Arreter le serveur 

docker compose down

## PORT UTILISÉS 

- 10823/udp (jeu)
- 10824/udp (query)
- 8080/tcp (interface web)

## CROSSPLAY

Le serveur est configuré pour permettre le crossplay PC/PS5/Xbox
